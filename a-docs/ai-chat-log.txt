MoGallery is a SwiftUI-based iOS app that wires together Firebase-backed
authentication, local camera/photo handling, and gallery/map views. The entry
point `MoGalleryApp` bootstraps Firebase, applies a custom navigation-bar
appearance, and injects shared singletons (`AppModel`, `CameraModel`,
`LobbyModel`, `GalleryModel`, `PhotosModel`, `MetaModel`, `LocationModel`) into
the root `LoginCheckView`, kicking off sign-in on appear.

```
15:45:MoGallery/MoGalleryApp.swift
@main
struct MoGalleryApp: App {
    var app = AppModel.main
    init() {
        UINavigationBar.applyCustomAppearance()
        FirebaseApp.configure()
        app.initRefresh()
    }
    var body: some Scene {
        WindowGroup {
            LoginCheckView()
                .environmentObject(AppModel.main)
                ...
                .environmentObject(LocationModel.main)
                .onAppear { app.lobbyModel.signIn() }
        }
    }
}
```

Key modules:

- `Auth/`: SwiftUI screens for onboarding and user management (`LoginView`, `UserDetailView`), plus app settings and lobby checks.
- `Camera/`: `CameraModel` + `CameraView` handle capture workflows, likely integrating AVFoundation for stills/video used elsewhere.
- `Commons/`: Reusable utilities (image caching, elapsed time formatting, Google sign-in button, location manager, thumbnail/viewfinder helpers).
- `Map/`: `LocationModel` with SwiftUI views for displaying captured media on a map tab.
- `Models/`: Core state containers (`AppModel`, `GalleryModel`, `PhotosModel`, etc.) coordinating data flow, uploads, and Firebase interactions.
- `Photos/`: Photo-library abstractions (`PhotoAsset`, `PhotoCollection`, `PhotosModel`) and views for browsing, picking, and detailing assets.
- `Store/`: Upload/download logic (`GalleryModel-upload`, `MediaModel-decode`, `MetaModel`) plus map views tied to stored metadata.
- `Views/`: High-level UI composition (`MainView`, `GalleryTabView`, `MediaDetailView`, `ShareSheet`, `WebView`) that stitch together models and feature modules.
- `Assets.xcassets`, `Preview Content`, and entitlements/plists provide app resources, Firebase config, and previews.

Overall: a modular SwiftUI app where models live as singletons injected via `environmentObject`, Firebase handles backend storage/auth, and the app spans authentication, media capture/upload, gallery browsing, and geospatial display.
